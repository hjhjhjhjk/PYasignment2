# PYasignment2
파이썬 과제2

## 1. 프로그램 소개
* 학기 말에 본인의 과목별 성적을 직접 입력하고, 입력된 점수들을 바탕으로 총점과 평균 학점을 쉽게 계산해보기 위해 직접 만든 프로그램입니다.

## 2. 주요 기능 및 구현 내용
* **딕셔너리(`{}`) 활용**: 과목명(Key)과 점수(Value)를 짝지어 저장하도록 구현했습니다.
* **예외 처리 예방**: 사용자가 점수에 숫자가 아닌 글자를 입력했을 때 프로그램이 멈추지 않고 에러 메시지를 띄우도록 `isdigit()`을 사용했습니다.
* **반복 제어**: 사용자가 3번을 누르기 전까지는 계속해서 성적을 추가하거나 조회할 수 있도록 `while True` 무한 루프를 활용했습니다.
